# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be kind, be honest about uncertainty, argue with measurements. Reports of
unacceptable behavior go to the maintainer via the repository's security
advisory channel or by email to fondues-cuckoo-1b@icloud.com, and will be
handled confidentially.
